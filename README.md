# qldzjml
乾隆大藏经目录

# pdf2png
这个是发现最原始pdf文件中，有不完整的图片，重新补全的办法

# qldzjocr
## ml
这个是从互联网上的网页中，解析出大藏经目录，保存未txt文件，作为基准。

## pic
这个是用baidu的船桨工具，把目录对应的图片挑选出来。然后把页面中的文字页解析出来，以备比较。

## contrast
这个是把网页的经文名和图片解析出来的经文名进行比较，如果相等，则找到了目录图片。这样，就可以在经名和大藏经的图片封面之间建立一一对应关系了。

# 结果
0. 匹配率大概超过50%，剩下大量需要手工进行校对。
1. 译者名，很对是没有对应图片的。经名是100%对应，但有时也还有微小错误。
2. 估计：最后结果中，经名的错误应该最少，对应的图片目录应该也是比较准的，但是译者名，只是手工校了一遍，估计还有一些错漏在。
3. 基本上没有发现有字，在现在的字库中没有的，有的异体字没有，但可以明确找到对应，也算有了。但是，这个缺少一个完整的说明，以备查备验。
